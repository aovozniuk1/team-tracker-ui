# Урок 2. Термінал і папки з нуля

*Claude Code живе в папці й говорить мовою команд: він відкриває файли за їхніми шляхами, запускає
команди в терміналі й показує тобі, що вони відповіли. Щоб розуміти, що він робить, і вміти
перевірити його роботу, тобі потрібен мінімум: що таке файл, папка і шлях, як відкрити термінал,
як у ньому пересуватися й читати відповідь. Після уроку ти відкриваєш термінал у потрібній папці,
створюєш папки, дивишся їхній вміст і розумієш, що означає помилка «шлях не знайдено».*

## Коротко

*Картка уроку: прочитай її перед уроком і повернись до неї після.*

**Одним реченням.** Термінал — це вікно, де ти пишеш команди текстом, а комп'ютер виконує їх у
поточній папці й відповідає текстом.

**Навіщо.** Claude Code завжди працює в одній папці (робочій директорії) і сам запускає команди;
без цих основ ти не зрозумієш, що він робить, і не перевіриш результат.

**Де.** Windows: **PowerShell** або **Terminal** (пошук у меню «Пуск»). macOS: застосунок
**Terminal** (`Cmd+Space`, набери `Terminal`). Linux: **Terminal** у меню застосунків.

**Модель**

- **Файл** — один документ: текст, таблиця, картинка, програма. Має ім'я і розширення (`notes.txt`).
- **Папка (директорія)** — контейнер для файлів та інших папок.
- **Шлях** — адреса файлу чи папки: перелік папок, через які до нього йти (`Documents\todo-app\index.html`).
- **Поточна (робоча) папка** — папка, «в якій ти стоїш» у терміналі; команди працюють саме тут.
- **Команда** — слово (і, можливо, параметри), яке ти набираєш і запускаєш клавішею `Enter`.

**Запам'ятай**

1. `pwd` — де я; `ls` — що тут лежить; `cd назва` — зайти в папку; `cd ..` — піднятися на рівень вище.
2. `mkdir назва` створює папку; `cd ~` повертає в домашню папку.
3. `Tab` доповнює назву файлу чи папки, стрілка `↑` повертає попередню команду.
4. `Ctrl+C` зупиняє команду, яка ще працює.
5. Відносний шлях рахується від поточної папки, абсолютний — від початку диска.

**Пастки** (симптом → причина)

- `Cannot find path ... because it does not exist` → ти не в тій папці або в назві помилка; спершу `pwd`, потім `ls`.
- Назва з пробілом «ламає» команду → візьми її в лапки: `cd "My Projects"`.
- Не бачиш папку `.claude` чи `.git` → вона прихована; `ls -a` на macOS/Linux, `ls -Force` у PowerShell.

**Як перевірити**

- Ти відкриваєш термінал, створюєш у папці «Документи» папку `ai-course`, заходиш у неї, і `pwd` показує шлях, що закінчується на `Documents\ai-course` (Windows) або `Documents/ai-course` (macOS/Linux).

## 2.1. Файли і папки

Усе, що зберігається на комп'ютері, — це **файли**. Документ Word, фото з телефона, таблиця,
сама програма Claude Code — кожне з них є файлом.

У файлу є **ім'я** і зазвичай **розширення** — частина після останньої крапки:

| файл | розширення | що це |
|---|---|---|
| `report.docx` | `.docx` | документ Word |
| `sales.xlsx` | `.xlsx` | таблиця Excel |
| `notes.txt` | `.txt` | простий текст |
| `index.html` | `.html` | вебсторінка |
| `app.js` | `.js` | програма на JavaScript |
| `README.md` | `.md` | текст у форматі Markdown |

Розширення підказує комп'ютеру, якою програмою відкривати файл. Для Claude Code воно теж важливе:
`.md` він читає як розмічений текст, `.js` — як код.

> **Порада для Windows.** Провідник за замовчуванням ховає розширення: ти бачиш `report`, а не
> `report.docx`. Увімкни їх: у Провіднику **View → Show → File name extensions** (українською:
> **Вигляд → Показати → Розширення імен файлів**). Без цього легко створити `notes.txt.txt` і
> довго не розуміти, чому файл «не знаходиться».

**Папка** (інша назва — **директорія**, від англ. *directory*) — це контейнер: у ній лежать файли й
інші папки. Папки вкладаються одна в одну, як коробки в коробки:

```
Documents
├── ai-course
│   ├── notes.txt
│   └── todo-app
│       ├── index.html
│       └── app.js
└── report.docx
```

Так малюють **дерево папок**: кожен відступ — один рівень вкладення. Тут папка `Documents` містить
папку `ai-course` і файл `report.docx`; у `ai-course` лежить `notes.txt` і ще одна папка `todo-app`.

⏸ **Зупинись і перевір себе.** У якій папці лежить `app.js`? А в якій — `todo-app`?

> **Відповідь.** `app.js` лежить у `todo-app`. А сама `todo-app` лежить у `ai-course`, яка, своєю
> чергою, лежить у `Documents`.

## 2.2. Шлях: адреса файлу

Щоб сказати комп'ютеру (або Claude), про який саме файл мова, потрібна його **адреса** — **шлях**.
Шлях — це перелік папок, через які треба пройти, і в кінці — сам файл:

```
Documents\ai-course\todo-app\app.js      (Windows)
Documents/ai-course/todo-app/app.js      (macOS, Linux)
```

Між назвами стоїть **роздільник**: на Windows — зворотна скісна риска `\`, на macOS і Linux —
звичайна `/`. PowerShell на Windows розуміє обидві, тож `Documents/ai-course` теж спрацює. Claude
Code у своїх повідомленнях часто пише `/` навіть на Windows — це нормально.

### Домашня папка і `~`

У кожного користувача комп'ютера є **домашня папка**: у ній лежать його «Документи»,
«Завантаження», «Робочий стіл». На Windows це папка з твоїм ім'ям користувача всередині `Users`
на системному диску, на macOS — `/Users/<ім'я>`, на Linux — `/home/<ім'я>`.

Щоб не писати її повністю, є скорочення — **тильда** `~`. Вона означає «моя домашня папка»:

```
~/Documents/ai-course
```

читається як «папка `ai-course` у моїх Документах». Ти зустрінеш тильду в Claude Code весь час:
наприклад, його особисті налаштування лежать у `~/.claude/`.

> **Windows з OneDrive.** Якщо «Документи» синхронізуються з OneDrive, Провідник показує їх у
> `~\OneDrive\Documents`, і `cd ~/Documents` може не знайти папку або привести не туди. Тоді в усіх
> командах курсу пиши `~/OneDrive/Documents` замість `~/Documents`.

### Абсолютний і відносний шлях

| вид шляху | від чого рахується | приклад |
|---|---|---|
| **абсолютний** | від початку диска або від домашньої папки (`~`) | `~/Documents/ai-course/notes.txt` |
| **відносний** | від **поточної папки** — там, де ти зараз стоїш | `todo-app/app.js` |

Аналогія: абсолютний шлях — повна поштова адреса («Україна, Київ, вул. Садова, 5, кв. 12»).
Відносний — пояснення сусідові («другий під'їзд, третій поверх»): працює, лише якщо ви вже стоїте
біля потрібного будинку.

Дві спеціальні назви у відносних шляхах:

- `.` (одна крапка) — «ця сама папка»;
- `..` (дві крапки) — «папка на рівень вище» (батьківська).

⏸ **Зупинись і перевір себе.** Ти стоїш у папці `ai-course` з дерева вище. Куди веде відносний
шлях `todo-app/index.html`? А `../report.docx`?

> **Відповідь.** `todo-app/index.html` — до файлу `index.html` у папці `todo-app` (вона всередині
> `ai-course`). `../report.docx` — на рівень вище, тобто в `Documents`, і там до `report.docx`.

### Приховані файли й папки

На macOS і Linux файли й папки, назва яких починається з крапки (`.claude`, `.env`, `.gitignore`),
вважаються **прихованими**: Finder і команда `ls` за замовчуванням їх не показують. Саме так
зберігаються налаштування багатьох програм, і Claude Code тут не виняток. На Windows крапка в назві
сама нічого не ховає: прихованим є лише файл чи папка з позначкою «прихований» (так git ховає свою
папку `.git`). Як побачити приховане — у розділі 2.4.

## 2.3. Що таке термінал і як його відкрити

**Термінал** (інші назви: командний рядок, консоль, shell) — це вікно, де ти керуєш комп'ютером
текстом. Замість «двічі клацнути папку» ти пишеш `cd назва`, замість «правий клік → Створити
папку» — `mkdir назва`.

Навіщо це, якщо є мишка? Три причини:

1. **Точність.** Команду можна прочитати, скопіювати, повторити. «Клацни там, потім там» — ні.
2. **Автоматизація.** Те, що робиш руками 100 разів, командою робиш один раз.
3. **Так працює Claude Code.** Він не клацає мишкою — він запускає команди. Коли ти бачиш у ньому
   рядок на кшталт `Bash: npm test`, це команда, запущена в терміналі. Розуміти термінал — означає
   розуміти, що робить Claude.

### Як відкрити

| система | як відкрити | що побачиш |
|---|---|---|
| **Windows 11** | правий клік на кнопці **Пуск** → **Terminal**; або натисни `Win`, набери `PowerShell`, `Enter` | вікно з рядком на кшталт `PS ...\Users\Olena>` |
| **Windows 10** | натисни `Win`, набери `PowerShell`, `Enter` | те саме |
| **macOS** | `Cmd+Space`, набери `Terminal`, `Enter` | рядок на кшталт `olena@MacBook ~ %` |
| **Linux** | меню застосунків → **Terminal** (у багатьох дистрибутивах `Ctrl+Alt+T`) | рядок на кшталт `olena@pc:~$` |

Рядок, що чекає на твою команду, називається **запрошенням** (англ. *prompt*). Не плутай із
промптом для Claude — у терміналі «prompt» означає саме цей рядок-запрошення. У ньому зазвичай
видно поточну папку: у PowerShell — після `PS`, на macOS — після імені комп'ютера (`~` означає
домашню папку).

> **Відкрити термінал одразу в потрібній папці.** Windows 11: у Провіднику відкрий папку, правий
> клік на порожньому місці → **Open in Terminal** (**Відкрити в терміналі**). macOS: перетягни
> папку з Finder на значок Terminal у Dock. Це найпростіший спосіб «стати» в папку проєкту.

### Як читати записи в цьому курсі

У прикладах рядок, який набираєш ти, починається з `>`. Цей знак не набирай — він лише показує,
де команда. Решта рядків — відповідь комп'ютера:

```
> pwd
Path
----
...\Users\Olena\Documents
```

## 2.4. Шість команд, яких вистачить на весь курс

Ці команди однакові (або майже) у PowerShell, на macOS і на Linux.

### `pwd` — де я?

*print working directory* — «покажи поточну папку».

```
> pwd
```

PowerShell відповідає таблицею з одним рядком `Path`, macOS і Linux — просто шляхом. Коли
загубився — почни з `pwd`.

### `ls` — що тут лежить?

*list* — «покажи вміст поточної папки».

```
> ls
```

У PowerShell побачиш таблицю: `Mode` (у першій позиції `d` — це папка, `-` — файл),
`LastWriteTime` (коли змінено), `Length` (розмір файлу в байтах) і `Name` (назва). На macOS і
Linux — просто перелік назв.

Варіанти:

| що треба | PowerShell | macOS / Linux |
|---|---|---|
| вміст поточної папки | `ls` (або `dir`) | `ls` |
| разом із прихованими | `ls -Force` | `ls -a` |
| вміст іншої папки, не заходячи в неї | `ls todo-app` | `ls todo-app` |

> У PowerShell `ls` і `dir` — це дві короткі назви однієї команди `Get-ChildItem`. Якщо Claude
> Code на Windows напише `Get-ChildItem`, знай: це той самий `ls`.

### `cd` — перейти в папку

*change directory* — «зайди в папку».

```
> cd Documents
> cd ai-course
> cd ..
> cd ~
```

- `cd Documents` — зайти в папку `Documents`, що лежить у поточній;
- `cd ..` — піднятися на рівень вище;
- `cd ~` — повернутися в домашню папку звідки завгодно;
- `cd ~/Documents/ai-course` — перейти одразу за абсолютним шляхом.

`cd` нічого не відповідає, коли все гаразд. Змінюється тільки запрошення — у ньому тепер нова
папка. Мовчання в терміналі зазвичай означає успіх.

### `mkdir` — створити папку

*make directory*.

```
> mkdir ai-course
```

PowerShell у відповідь покаже табличку з новою папкою; macOS і Linux мовчать. Перевір результат
через `ls`.

### `cls` / `clear` — очистити екран

Прибирає весь текст із вікна. Нічого не видаляє й не скасовує — просто чистить екран.
У PowerShell працюють обидві назви, на macOS і Linux — `clear`.

### `exit` — закрити термінал

Закриває сесію терміналу (те саме, що закрити вікно).

⏸ **Зупинись і перевір себе.** Ти в домашній папці. Яку послідовність команд набрати, щоб створити
в «Документах» папку `practice`, зайти в неї й переконатися, що ти там?

> **Відповідь.** `cd Documents`, `mkdir practice`, `cd practice`, `pwd`. Останній рядок відповіді
> `pwd` має закінчуватися на `Documents\practice` (Windows) або `Documents/practice`
> (macOS/Linux).

## 2.5. Прийоми, що економлять час

| прийом | що робить | приклад |
|---|---|---|
| `Tab` | доповнює назву файлу чи папки | набери `cd Doc`, натисни `Tab` → `cd Documents` (у PowerShell може з'явитися `.\Documents`, це те саме) |
| `↑` / `↓` | гортає попередні команди | натисни `↑`, щоб повторити останню команду |
| `Ctrl+C` | зупиняє команду, що зараз працює | команда «зависла» або робить не те |
| права кнопка / `Ctrl+V` (macOS: `Cmd+V`) | вставити скопійований текст | вставити команду з уроку |
| лапки | назва з пробілами | `cd "My Projects"` |

`Tab` — найкорисніший прийом: він не лише економить час, а й захищає від помилок. Якщо `Tab`
нічого не доповнив, такої назви в поточній папці немає — і ти дізнаєшся про це до запуску команди.

> **Про `Ctrl+C`.** У терміналі це не «копіювати», а «перервати». Щоб скопіювати текст із вікна
> терміналу, виділи його мишкою: у Windows Terminal далі `Ctrl+Shift+C` (або просто `Ctrl+C`,
> коли текст виділено), на macOS — `Cmd+C`. У Claude Code `Ctrl+C` теж перериває, а подвійне
> натискання на порожньому рядку виходить із програми — це буде в уроці 3.

## 2.6. Команда, вивід і помилка

Кожна команда в терміналі працює однаково:

1. Ти набираєш команду і натискаєш `Enter`.
2. Комп'ютер виконує її **в поточній папці**.
3. Він друкує **вивід** (англ. *output*) — результат або повідомлення про помилку.
4. З'являється нове запрошення: можна вводити наступну команду.

Поки команда працює, нового запрошення немає. Деякі команди працюють довго (встановлення програм,
запуск тестів), і це нормально.

### Як читати помилку

Спробуй зайти в папку, якої немає:

```
> cd no-such-folder
Set-Location: Cannot find path '...\no-such-folder' because it does not exist.
```

(у старішому Windows PowerShell рядок починається з `cd :`; на macOS буде
`cd: no such file or directory: no-such-folder`).

Розбери його так само, як розбирав би баг-репорт:

| частина | що означає |
|---|---|
| `Set-Location` | яка команда скаржиться (`cd` — її коротка назва) |
| `Cannot find path` | що сталося: шлях не знайдено |
| `'...\no-such-folder'` | який саме шлях вона шукала — повний, від поточної папки |
| `does not exist` | чому: такого немає |

Головне правило: **помилку читають повністю, а не лише слово «error»**. У ній майже завжди
написано, що, де і чому. Саме тому в уроках про промпти ми вчитимемось вставляти Claude **повний
текст помилки**, а не «воно не працює».

⏸ **Зупинись і перевір себе.** Ти набрав `cd todo-app` і отримав `Cannot find path`. Назви дві
найімовірніші причини і як перевірити кожну.

> **Відповідь.** 1) Ти не в тій папці — перевір `pwd`. 2) Назва написана інакше (`todo_app`,
> `Todo-App`) або папки взагалі немає — перевір `ls`. На Windows регістр літер у назвах не важливий,
> на macOS зазвичай теж, а на Linux — важливий: `Todo-App` і `todo-app` там різні папки.

## 2.7. Робоча папка — центральне поняття для Claude Code

**Робоча папка** (*working directory*) — це та сама поточна папка, з якої ти запускаєш програму.
Для Claude Code вона особлива: це **проєкт**, у межах якого він працює.

- Файли **всередині** робочої папки Claude читає без запитів дозволу.
- Читання **поза** нею, а також більшість змін файлів і запуск команд контролюють **дозволи**
  (урок 9).
- Налаштування й пам'ять Claude Code прив'язані саме до цієї папки: інша папка — інший проєкт.

Звідси звичка, яку варто виробити з першого дня: **перш ніж запускати Claude Code, перейди в папку
проєкту.** Запуск із домашньої папки означає, що «проєктом» стає вся твоя домашня папка — з
документами, фото й завантаженнями. Це і повільніше, і ризикованіше. До того ж, коли Claude Code
вперше запускається в новій папці, він питає, чи довіряєш ти їй (про це — в уроці 3); у домашній
папці ця відповідь не зберігається, і питання повторюється при кожному запуску.

```
> cd ~/Documents/ai-course/todo-app
> pwd
> claude
```

(команду `claude` ти встановиш у наступному уроці).

⏸ **Зупинись і перевір себе.** Чому погана ідея запускати Claude Code в домашній папці, щоб
«попросити розібрати один файл у Документах»?

> **Відповідь.** Робочою папкою стане вся домашня папка: Claude отримає доступ до читання всього,
> що в ній лежить, пошук по ній буде довгим, а налаштування й пам'ять проєкту «прилипнуть» до
> домашньої папки. Краще перейти в папку з потрібним файлом або створити окрему папку й покласти
> файл туди.

## 2.10. Типові помилки

### Симптом → причина

| симптом | причина | що зробити |
|---|---|---|
| `Cannot find path` / `no such file or directory` | ти не в тій папці або помилка в назві | `pwd`, потім `ls`, далі `Tab` для назви |
| `cd My Projects` не працює | пробіл розділив назву на дві частини | лапки: `cd "My Projects"` |
| файл `notes.txt` «не знаходиться», хоча видно в Провіднику | він насправді `notes.txt.txt` | увімкни розширення в Провіднику, перевір `ls` |
| не видно `.claude` чи `.env` (macOS, Linux) або `.git` (Windows) | вони приховані | `ls -a` (macOS, Linux) / `ls -Force` (PowerShell) |
| вставив команду, а вона одразу запустилась із помилкою | разом із командою скопіювався символ `>` з уроку | вставляй лише текст після `>` |
| `Ctrl+C` «не копіює» | у терміналі це «перервати» | виділи текст; `Ctrl+Shift+C` у Windows Terminal, `Cmd+C` на macOS |
| команда «висить» без нового запрошення | вона ще працює або чекає твоєї відповіді | прочитай останні рядки; якщо треба — `Ctrl+C` |

## 2.11. Що варто запам'ятати

1. Файл має ім'я й розширення; папка — контейнер; вони складаються в дерево.
2. Шлях — адреса: на Windows через `\`, на macOS/Linux через `/`; `~` — домашня папка.
3. Відносний шлях рахується від поточної папки; `..` — рівнем вище.
4. Шість команд: `pwd`, `ls`, `cd`, `mkdir`, `cls`/`clear`, `exit`.
5. `Tab` доповнює, `↑` повторює, `Ctrl+C` перериває.
6. Помилку читають повністю: що, де, чому.
7. Claude Code працює в **робочій папці** — перейди в папку проєкту, перш ніж його запускати.
8. На macOS/Linux файли з крапки на початку приховані (`ls -a`); на Windows приховані лише позначені
   так файли, як-от `.git` (`ls -Force`).

# Розв'язки

**2.1.** Файл — один документ із вмістом (текст, картинка, таблиця, програма); у нього є ім'я й
розширення. Папка — контейнер, у якому лежать файли й інші папки; власного «вмісту» в неї немає.
Приклади файлів: `cv.pdf` (PDF-документ), `photo.jpg` (фото), `budget.xlsx` (таблиця Excel).

**2.2.** Зразок:
```
Downloads
├── invoices
│   ├── 2026-09.pdf
│   └── 2026-10.pdf
├── setup.exe
└── photo.jpg
```
Кожен відступ — рівень вкладення; файл чи папка під іншою папкою лежить у ній.

**2.3.** Відносний: `ai-course/todo-app/index.html` (на Windows можна й `ai-course\todo-app\index.html`).
Абсолютний: `~/Documents/ai-course/todo-app/index.html`.

**2.4.** Найчастіше `pwd` покаже домашню папку (шлях, що закінчується твоїм ім'ям користувача): саме
там термінал стартує за замовчуванням. Якщо ти відкрив його через «Open in Terminal», `pwd` покаже
ту папку, з якої відкривав.

**2.5.**
```
> cd ~/Documents
> mkdir ai-course
> mkdir ai-course/practice
> mkdir ai-course/notes
> ls ai-course
```
`ls ai-course` має показати дві папки: `notes` і `practice` (у PowerShell у колонці `Mode` у них `d`).

**2.6.** `cd ../notes`. `..` піднімає з `practice` в `ai-course`, далі `notes` — уже звідти.
Перевірка: `pwd` закінчується на `ai-course\notes` або `ai-course/notes`.

**2.7.** PowerShell 7: `Set-Location: Cannot find path '...\notes-typo' because it does not exist.`
Команда — `Set-Location` (тобто `cd`); що — шлях не знайдено; який — повний шлях до
`notes-typo` від поточної папки; чому — такого немає. Виправлення — `ls`, щоб побачити справжню
назву, і `Tab` для доповнення.

**2.8.** Після «Open in Terminal» запрошення вже містить шлях до `ai-course`, а `pwd` показує шлях,
що закінчується на `Documents\ai-course` (`Documents/ai-course`). Якщо пункту меню немає (Windows 10),
відкрий PowerShell і перейди командою `cd ~/Documents/ai-course`.

**2.9.** `cd ~`, потім `ls -Force` (Windows) або `ls -a` (macOS/Linux). Типові назви з крапкою:
`.claude`, `.gitconfig`, `.ssh`, `.vscode`, `.npm`, `.cache`. Їхній набір залежить від того, що
встановлено на комп'ютері. На Windows ці назви видно й звичайним `ls`, а `ls -Force` додає справді
приховане (наприклад, `AppData`); на macOS/Linux їх показує лише `ls -a`.

**2.10.** `cd Doc` + `Tab` доповнюється до `cd Documents` (або `cd .\Documents\` у PowerShell) —
така папка існує. `cd Xyz` + `Tab` нічого не змінює — назви, що починається на `Xyz`, у поточній
папці немає. `Tab` — це перевірка «чи існує те, що я хочу набрати», ще до запуску команди.

**2.11.** `cd ~` — у домашню папку; `cd Documents/ai-course` — у `ai-course` в Документах;
`cd ..` — на рівень вище, у `Documents`; `pwd` покаже шлях, що закінчується на `Documents`.

**2.12.** Після відкриття термінал стоїть у домашній папці, тож Claude Code отримає її як проєкт:
доступ на читання до всіх особистих файлів, довгі пошуки, налаштування й пам'ять, прив'язані не до
того місця. Правильно: спершу `cd` у папку проєкту (або «Open in Terminal» у ній), перевірити `pwd`,
і тільки потім запускати.

**2.13.**
```
> cd ~/Documents/ai-course
> mkdir "my project"
> cd "my project"
> cd ..
```
Без лапок `mkdir my project` створить **дві** папки — `my` і `project`, бо пробіл розділяє
аргументи команди. Лапки кажуть: «це одна назва». (Тому в назвах робочих папок краще уникати
пробілів: `my-project`.)

**2.14.** Збережи файл через **File → Save As**, обери папку `Documents\ai-course\notes`, ім'я
`terminal.txt`. Перевірка:
```
> cd ~/Documents/ai-course/notes
> ls
```
У колонці `Name` має бути рівно `terminal.txt`. Якщо бачиш `terminal.txt.txt`, Провідник
приховував розширення, а Блокнот додав своє: перейменуй файл і ввімкни показ розширень (розділ 2.1).
